# Historical working files

These are the original top-level authored scratch scripts from the investigation, retained so failed approaches and implementation corrections remain inspectable. They are not an automated pipeline. Several scripts patch earlier versions of files or replace saved results; read them before running anything. Most expect the current working directory to be the parent `Chesewip/` directory.

The primary reviewable research is in [../outputs/](../outputs/README.md). The two `pg*.txt` files are the original language-control corpora with their complete Gutenberg notices, attribution and licenses. Reference clones, downloaded research documents and dependency installations are omitted from Git; see [../REFERENCES.md](../REFERENCES.md).
